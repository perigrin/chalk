## Executive Summary

This segment lets the inliner lower a callee that branches, loops or stores, and stops dropping a statement that follows a nested if or loop. As first reviewed (4e1e9969), it gave silent wrong answers on ordinary programs, all in shapes the corpus does not contain:
- **Shared nodes between subs.** Two analysis passes built every sub's coercion nodes from one shared node factory, so an inlined callee could test its caller's value.
- **A doubled effect.** A call reached through a straight-line callee ran its effects twice.
- **Other failures.** A callee could read a caller's variable, and a sub ending in an `if` produced a module lli rejected.

All of these are fixed, each against a test that failed first (4182d850). The verifier then found one regression from the factory fix: an `Int` value where the call expected a `Num`. That is also fixed (e1a15d3a). No in-scope finding is open. Five pre-existing bugs went to the backlog. Confidence is high: about 460 probe programs were run through B::SoN, chalk and lli and compared with perl.

## Critical Issues

### [C1] One node factory for every graph: an inlined callee read its caller's value — FIXED 4182d850
- **File:** `lib/Chalk/IR/Analysis.pm:1380`, `:1473`
- **Bug:** `_insert_str_coercions` and `_narrow_unknown_coercions` built every graph's nodes from one NodeFactory. Node ids are per graph and nodes are hash-consed, so `f`'s `Coerce(shift#2)` and main's `Coerce(g(5)#2)` came out as the same node.
- **Impact:** `f(1)` printed `F` (it tested main's `g(5)`), `h(1)+f(2)` printed `hh3` for `hb3`, `f(2)+f(3)` was refused as "recursive", and an unrelated sub's `shift` was counted as the callee's own.
- **Fix:** one factory per graph.
- **Confidence:** High
- **Found by:** Logic & Correctness, Spec Compliance, Contract & Integration, Concurrency & State (`claude-opus-5-5[1m]`)

### [C2] A sub ending in an if: lli rejected the module — FIXED 4182d850
- **File:** `lib/Chalk/Target/LLVM/Context.pm` `_lower_inlined_structure`, `_coerce_arm`
- **Bug:** The sub's implicit value is the `if`'s value, which comes from a `print` inside an arm. That value was used past the merge.
- **Fix:**
  - **If without else:** refused by name.
  - **If/else:** the arms' prints are boxed into the merge phi, so it now gives perl's answer.
- **Confidence:** High
- **Found by:** Error Handling (`claude-opus-5-5[1m]`)

### [C3] A call reached through a straight-line callee ran its effects twice — FIXED 4182d850
- **File:** `lib/Chalk/Target/LLVM/Context.pm` `_lower_inlined_effects_then_value`
- **Bug:** The callee's effects were lowered under a fresh cache and its value under the caller's cache. A call reachable from both was therefore lowered, and run, twice: `x x 6` for `x 6`, and `HH7` for `H7` (the last was already wrong at base).
- **Fix:** the value is lowered in the same frame as the effects.
- **Confidence:** High
- **Found by:** Contract & Integration, Concurrency & State (`claude-opus-5-5[1m]`)

## Important Issues

### [I1] The callee started with a copy of the caller's variables — FIXED 4182d850
- **File:** `lib/Chalk/Target/LLVM/Context.pm` `_lower_inlined_structure`
- **Bug:** Variable ids collide between graphs, so callee `VarDecl#1` read caller `VarDecl#1`. A hand-built graph printed 8 for 10.
- **Fix:** the callee's variable table now starts empty.
- **Test:** `llvm-an-inlined-callee-has-its-own-variables.t`
- **Found by:** Concurrency & State (`claude-opus-5-5[1m]`)

### [I2] `_graph_component` walked out of the callee — FIXED 4182d850
- **Bug:** The walk followed every consumer, so it crossed into other subs' graphs through shared nodes.
- **Fix:** it now walks backward over data and control edges, and forward only from control nodes.
- **Found by:** Contract & Integration, Concurrency & State (`claude-opus-5-5[1m]`)

### [I3] A nested call's Int value went where the call expected a Num — FIXED e1a15d3a
- **File:** `lib/Chalk/Target/LLVM/Context.pm` `_lower_call_direct`
- **Bug:** A regression from C1's fix. `sub g { $_[0] * 2 } sub f { g($_[0] + 1) }` produced a module lli rejected. Separately, `f(1), f(3)` gave `4 4` for `4 8` at a7023ef3.
- **Fix:** the inlined value is coerced to the call's scalar repr.
- **Found by:** Verifier (`claude-opus-5-5[1m]`)

### [I4] Tests accepted any refusal — FIXED 4182d850
- **Bug:** The tests could not catch a lowered shape falling back to a refusal.
- **Fix:** `llvm-a-call-to-a-sub-with-effects.t` now requires perl's exact output for every shape that lowers. Reverting the `_graph_component` change fails 9 of its tests.
- **Found by:** Spec Compliance (`claude-opus-5-5[1m]`)
